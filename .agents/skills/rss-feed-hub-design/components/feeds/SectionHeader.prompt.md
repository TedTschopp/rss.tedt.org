Section opener with the system's signature 2px ink rule; optional orange mono eyebrow and right-aligned mono meta.

```jsx
<SectionHeader eyebrow="FEEDS" title="Available Feeds" meta="5 FEEDS · 386 ENTRIES" />
```

- Use at the top of every page section; the 2px rule spans the full column.
- `action` accepts an element (e.g. `<Button size="sm" variant="outline">`) instead of `meta`.
