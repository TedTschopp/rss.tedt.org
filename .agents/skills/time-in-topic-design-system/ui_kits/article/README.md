# Article UI kit — Yesterday in AI

Single-story detail page. Narrow reading column (760px max), serif body throughout.

## Files
- `index.html` — interactive article view with hero, body, callout, related strip.
- `Components.jsx` — `ArticleHeader`, `ArticleHero`, `ArticleBody`, `RelatedStrip`.

## Notes
- Reading column is 680px (`--w-prose`) inside a 760px page. Generous margins, no rail.
- The "What it changes" callout uses a left accent rule and warm subtle fill — the only place a soft fill is allowed in the article context.
- Source link appears twice: once as a primary CTA in the hero actions, once as the canonical attribution at the article foot.
